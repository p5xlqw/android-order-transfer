順番転送ツール 1.0.5

起動
1. ZIPを展開します。
2. 「起動.bat」をダブルクリックします。
3. PCのフォルダまたはZIPを選び、プレビューで順番を確認して転送します。

転送順プレビューには、選択中の並び替え項目と各ファイルの値を表示します。並び替え項目には名前・拡張子・サイズ・各日時のほか、Windowsが取得できる音声・映像・全体のビットレートなど、音声、動画、写真、文書の共通メタデータを使えます。取得可能な項目はファイル形式やWindowsのプロパティハンドラーによって異なります。

転送順プレビューで画像・音声・動画ファイルをダブルクリックすると、Windowsの既定アプリで開いて確認できます。実行可能ファイルやスクリプトなどは開きません。

必要な環境
Windows 10/11、Python 3.10以上、USB接続したAndroid端末（ファイル転送モード）。
モニターのDPIに合わせてUI寸法とフォントを拡大し、Windowsによる低解像度画面の後拡大を避けます。
