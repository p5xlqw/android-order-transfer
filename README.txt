順番転送ツール 1.0.4

起動
1. ZIPを展開します。
2. 「起動.bat」をダブルクリックします。
3. PCのフォルダまたはZIPを選び、プレビューで順番を確認して転送します。

並び替え
名前、拡張子、ファイルサイズ、各日時のほか、Windowsが取得できる共通メタデータで並び替えできます。動画の解像度・フレームレート・ビットレート、音声情報、写真情報、文書情報にも対応します。候補は選択中の全ファイルに値がある項目に限られ、取得可能な値はファイル形式とWindowsのプロパティハンドラーによって異なります。プレビュー行のドラッグで順番を調整できます。

必要な環境
Windows 10/11、Python 3.10以上、USB接続したAndroid端末（ファイル転送モード）。
