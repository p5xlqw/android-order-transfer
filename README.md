# 順番転送ツール

Windows PCから、USB接続したAndroid端末へファイルを選択順に一つずつ転送するための試作です。Windowsのエクスプローラーが使うMTP対応シェル機能を通して端末の保存先を参照します。

## 起動

Windows 10/11でPython 3が利用できる環境なら、フォルダ内で次を実行します。

```powershell
python main.py
```

端末をUSB接続し、Android側のUSB用途を「ファイル転送」にしてから「再検索」を押します。PC側フォルダを選び、並び順と端末側の転送先を指定して、プレビューを確認してから転送します。

## 現在の範囲

- PCフォルダ直下のファイルを名前・拡張子・サイズ・更新日時・作成日時・アクセス日時と、Windowsが取得できる共通メタデータで昇順／降順に並べます。音声・動画・画像・文書のトラック番号、音声・映像・全体のビットレート、動画解像度やフレームレート、撮影情報、ページ数などは、選択フォルダ内の全ファイルに値がある項目だけ候補に表示します。項目の取得可否はWindowsのプロパティハンドラーやファイル内の情報に依存します。名前順は数字を自然順で比較します（例: 1, 2, 10）。
- ウィンドウは固定サイズで、転送順プレビューは一度に10件表示します。
- モニターのDPIに合わせてアプリ内でUI寸法とフォントを拡大し、Windowsによる低解像度画面の後拡大を避けます。
- ZIPファイルを選んで中身を展開し、端末へ転送できます。ZIP内のフォルダ構成を保ち、転送先にも必要なフォルダを作成します。危険なパスやリンクを含むZIPは展開しません。
- 送信元は「フォルダを選択…」または「ZIP／CBZを選択…」から指定できます。Windows標準のフォルダ選択／ファイル選択画面が直接開きます。
- プレビューの行をドラッグして、現在の並び順を手動調整できます。調整後も選択中の並び替え項目を表示します。ドラッグ中はファイル名だけを表示し、差し込み位置を線で示します。
- 転送順プレビューには、選択中の並び替え項目の値をファイル名とサイズの間に表示します。
- プレビューで画像・音声・動画ファイルをダブルクリックすると、Windowsの既定アプリで開いて確認できます。実行可能ファイルやスクリプトなどは開きません。
- 「下から転送」を選ぶと、プレビューの順番を保ったまま実際の転送順だけを逆順にできます。
- 転送終了後は、実際に送った順でファイルごとの完了・スキップ・失敗・未実行を一覧表示します。
- 拡張子フィルターで対象を絞れます。初期設定はすべての拡張子です。
- MTPで公開される端末フォルダをツリー表示します。
- 転送先は選択した既存フォルダか、新規作成するフォルダから選べます。新規フォルダ名は送信元フォルダ名を初期値にし、転送前に編集できます。新規作成を選ぶと、端末または任意のフォルダを作成場所に指定できます。同名フォルダが既にある場合は転送を開始しません。
- 既存の同名ファイルを上書きせず、転送前に検出して停止します。
- 1ファイルずつ転送し、次のファイルへ進む前に端末側でファイルが見え、サイズが安定したことを確認します（MTP側のサイズ表示が元ファイルと異なる場合にも対応）。
- 「同名ファイルをスキップ」を選ぶと、転送先に同じ名前のファイルがある場合は上書きせず飛ばして続行します。
- 転送中止ボタンがあり、現在のファイルを確認してから次のファイルへ進まず停止します。
- 転送中にウィンドウを閉じると中止要求を送り、現在のファイルが完了確認されるまで待ってから終了します。転送前確認中なら、端末への転送を始めず終了します。
- USB切断または端末の無応答が起きた場合は転送全体を停止し、中止状態を短く表示してアプリを自動終了します。途中からの再開や端末側ファイルの自動削除はしません。端末に一部ファイルが残る可能性があるため、やり直す場合は空の新規フォルダを使います。
- 端末検索・フォルダ読込・メタデータ確認・転送前確認にも応答期限があります。応答しない場合は転送機能を停止し、アプリの再起動を案内します。
- ZIPの展開中は進行状況を表示します。展開中にアプリを閉じた場合は展開を中止し、一時ファイルを片付けます。
- 転送先はフォルダを1回クリックして選択でき、選択中の端末名とフォルダ階層を表示します。
- 転送状況はバーとパーセンテージで表示します。端末からサイズ情報を取得できる間は転送量も表示し、取得できない場合は完了ファイル数を基に進み具合を表示します。
- 転送中は経過時間、平均速度、残り時間の目安を表示します。現在のファイルと端末側で完了確認済みの件数も区別して表示します。
- 転送前に同名ファイルを確認し、送信元・件数・順番・合計サイズ・保存先・同名ファイル数をまとめて表示します。
- フォルダ配下の再帰転送、既存ファイルの削除は行いません。

中止は現在のファイルの完了を確認した後に反映されます。MTPの転送自体を途中で強制切断しないため、停止を押した直後に現在のファイルが端末へ保存される場合があります。MTPが応答しない場合は待ち続けず転送全体を失敗として停止します。

MediaStoreの追加日時がこの転送順に従うかは、端末とアプリで異なる可能性があります。この試作では実際のAndroid端末上での検証が必要です。
